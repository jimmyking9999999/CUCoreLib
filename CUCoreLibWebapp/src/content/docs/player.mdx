## The player object

The player is the vanilla `Body` component. Get the local player with:

```csharp
Body body = PlayerCamera.main.body;
// For multiplayer, use 
// Body body = CUCoreUtils.TryGetBody();
float hunger = body.hunger;
```
---

## Changing values vanilla recalculates

Some `Body` fields, like `heartRate` or `maxEncumberance`, are recalculated by vanilla every frame or second, so writing to them directly is overwritten right away.

`CCLBody` adds your own offset into vanilla's formula instead:

```csharp
CCLBody.MaxEncumberance = 10f; // the player can carry 10u more
CCLBody.HeartRate = 15f;       // heart beats 15f faster
```

- Each value is **an offset that stays until you change it**, not a one-off nudge. So set it (`=`), and set it back to `0` when your effect ends, wearable gets removed, etc.... 
- This means, Using `+=` every frame would keep stacking. Don't do this!


| Offset | Adds to |
| --- | --- |
| `BloodPressure` | Target blood pressure (vanilla clamps it to 0–250). |
| `HeartRate` | Target heart rate. |
| `RespiratoryRate` | Target breathing rate (clamped to 0–100). |
| `MaxEncumberance` | How much weight the player can carry. |
| `TotalEncumberance` | How much weight the player is carrying. |
| `Immunity` | Immune strength. |
| `MaxSpeed` | Movement speed. |
| `JumpSpeed` | Jump height. Use this instead of `body.jumpSpeed`, which is permanent and stacks across loads. |
| `AveragePain` | Overall pain, without showing on any limb. |

The real result still lives on the vanilla field, so you keep reading `body.heartRate`, `body.maxEncumberance`, and so on.

## Common Body fields

Fields you can safely read, and change directly unless noted.

| Field | What it is |
| --- | --- |
| `hunger`, `thirst` | Food and water meters. Prefer `Eat(hunger, weight)` and `Drink(amount)` to raise them. |
| `stamina`, `energy` | Short-term stamina and tiredness. |
| `consciousness` | `100` is fully awake. |
| `happiness` | Mood. Vanilla slowly pulls it back toward `0`. |
| `temperature` | Core temperature in °C (normal is around 37). |
| `bloodVolume`, `bloodOxygen` | Blood amount and oxygen. |
| `heartRate`, `bloodPressure` | Recalculated, use `CCLBody` to change. |
| `brainHealth` | `0` means death. |
| `shock` | Pain shock. High values incapacitate. |
| `sicknessAmount`, `radiationSickness` | Sickness and radiation sickness. |
| `wetness`, `dirtyness` | How wet and dirty the player is. |
| `weightOffset` | Body weight gained or lost (food, liquids). |
| `totalEncumberance`, `maxEncumberance` | Carried weight and limit. Recalculated, use `CCLBody` to change. |
| `sleeping`, `crouching`, `grounded`, `inWater` | State flags. |

| Reference | What it is |
| --- | --- |
| `limbs` | Every `Limb` (see below). Same order as the `setlimbfield` console command. |
| `talker` | Speech bubbles: `body.talker.Talk("Hello!")`. |
| `skills` | Skill levels, e.g. `body.skills.INT`. |
| `slots` | Inventory and hand slots. |
| `rb` | The `Rigidbody2D`, for physics and velocity. |

## Limb fields

Wounds and treatment happen per `Limb`. Loop over `body.limbs` for body-wide effects, e.g:

```csharp
foreach (Limb limb in body.limbs)
    limb.pain = Mathf.Max(0f, limb.pain - 10f);
```

| Field | What it is |
| --- | --- |
| `fullName`, `shortName` | Display names. |
| `skinHealth`, `muscleHealth` | `0`–`100`. |
| `pain` | Pain in this limb. |
| `bleedAmount` | How much it bleeds. |
| `broken`, `dislocated`, `splinted` | Bone state. |
| `infected`, `infectionAmount` | Infection. `infectionAmount` only grows while `infected` is true. |
| `dismembered` | Whether the limb is gone. |
| `isHead`, `isArm`, `isLegLimb`, `isVital` | What kind of limb it is. |
| `body` | The `Body` it belongs to. |

## Player events

`CUCoreUtils` raises several events you can subscribe to, such as `OnHealPlayer` and `OnLastStand`!
-  See [CUCoreUtils](/docs/utils/) for the list.

{/* Code shown in the side panel */}

```csharp panel title="PlayerHelpers.cs"
using System.Collections;
using CUCoreLib.Helpers;
using UnityEngine;

// Inside your Plugin class: StartCoroutine(LogPlayerWhenReady());
private IEnumerator LogPlayerWhenReady()
{
    Body body = PlayerCamera.main.body;
    Logger.LogInfo($"Hunger={body.hunger}, Thirst={body.thirst}, Temp={body.temperature}");
}

// A heavy backpack effect. We call with true when equipped, false when removed
public static void SetBackpackEffect(Body body, bool active)
{
    // Target this exact player, so it works in multiplayer too
    using (CCLBody.Use(body))
    {
        CCLBody.MaxEncumberance = active ? 15f : 0f; // carry 15 more
        CCLBody.MaxSpeed = active ? -1f : 0f;        // but move a bit slower
    }
}

// Ease every limb's pain a little
public static void SoothePain(Body body)
{
    foreach (Limb limb in body.limbs)
    {
        limb.pain = Mathf.Max(0f, limb.pain - 10f);
    }
}
```
